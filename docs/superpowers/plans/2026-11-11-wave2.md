## Global Constraints

Everything in `2026-11-10-wave1.md` "Global Constraints" still holds: commit style, failing test first, fmt, clippy -D warnings and the full test before each commit, scrubbing, root never running agent-placed files, side containers only, and DESIGN and README updated in the same task. In addition:

- **Current state:** main runs rpi 0.21.2 (`/home/user/Projects/.always-on/rpi-0.21.2/bin/rpi`; ignored tests with `ZEPHYR_REAL_RPI=1`). `SCHEMA_VERSION` is 18. DESIGN's last section is §4.20. New DESIGN sections, in merge order, are §4.21 onward.
- **New crates:** only `rcgen`, plus `rustls` and `tokio-rustls` if not already present (A3). Run `cargo deny check advisories bans` after any dependency change.
- **The network floor (§4.20) is the default.** Every new listener binds through `egress::listen_addr` and is listed in `egress::published`. The daemon's own clients (Telegram, signal-cli) run as root and connect directly. Nothing new may be reachable by the agent's uid.
- **New image content goes in `deploy/Dockerfile` behind build args:**
  - C1: `SIGNAL`, default on.
  - C2: `VOICE` (default on) and `KO_VOICE` (default off).
  - E: `RPI_PACKAGE_REPO` and `PLUGINS_REPO`.
  - Every `COPY` source must pass `every_copy_in_the_dockerfile_is_in_the_build_context`.
- **The image must build.** Each lane that touches `deploy/` runs one `docker build` as `zephyr-dev:<lane>-<sha>` and checks the result in a side container (`ZEPHYR_CONTAINER=zephyr-test`). Remove the side container when done. Never touch the live `zephyr` container or `~/.zephyr*`.
- **Never `tailscale serve`** or change the host's real tailscale config; use a stand-in on PATH as W did.

## Review Focus

1. **A3: a surrogate sent to an unbound host, or to a bound host's look-alike** (DNS rebinding, `Host` header mismatch, a CONNECT to the bound name with SNI for another): never swapped. It is refused and audited where the proxy can see it.
2. **A3: a CA the agent planted** (its own `SSL_CERT_FILE`, NSS db or `NODE_EXTRA_CA_CERTS`): it gains no trust in root's or the proxy's upstream checks.
3. **C1: a stranger messaging the bot or the Signal number, or adding the bot to a group:** ignored, no files fetched, and the bot leaves the group.
4. **C2: a forged voice-note file planted in `inbox/`:** never transcribed (only bytes the daemon fetched itself). A transcript taints the conversation (`inbox.derived`) and is never read as a command.
5. **C2: the agent reaching x11vnc or acting while the owner holds the desktop:** x11vnc listens nowhere, and browser and xdotool calls wait at the gate.
6. **E: every default is unchanged:**
   - the image stays `ghcr.io/yansigit/zephyr:<version>` and the full provider set still builds;
   - `zephyr init` re-run on the owner's install leaves its config files byte-identical;
   - `zephyr pull` sends the `gh` token only to ghcr.io.
