# Phone calls (D2-calls) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Main's agent can ask to phone a Canadian number for a stated purpose; the owner approves each call on a card, the daemon places it on Telnyx, speaks a fixed disclosure, lets a tool-less call child talk through local whisper and Piper, shows the owner the transcript live, and ends the call at `/hangup`, the cap, silence or the other side's hang-up.

**Architecture:** `calls/mod.rs` is pure: the number rules, the CRTC hours, the texts, the settings. `calls/telnyx.rs` is the one `Telephony` implementation: Call Control over the daemon's own `reqwest` client, and the ed25519 check of Telnyx's media connection and webhooks. `calls/live.rs` holds the listener (`/calls/<token>` and `/calls/events` only), the registry of live calls and one task per call that joins Telnyx's media WebSocket, an energy endpointer, `voice.rs` (whisper in, Piper out, as `nobody`) and an rpi child `call-<id>` started with `--no-tools`. The gate holds every `call` (kind `call`, class `messages`), `actions::approve` starts it, and the end is an inbox row with `derived = 'call'`.

**Tech Stack:** Rust, no new crates (`ring` for ed25519, `tokio-tungstenite` for the media socket, `hyper` for the listener, `reqwest` for Telnyx, `jiff` for the recipient's clock). Telnyx Call Control v2 and media streaming. Tests: `tests/fake-telnyx.py` (stdlib Python: HTTP API, a WebSocket client, pure-Python ed25519), `tests/fake-rpi.py`, the voice stand-ins.

**Spec:** `docs/superpowers/specs/2026-11-12-calls-cards-design.md`, the calls parts only (§4.1 `Telephony`, §4.8 to §4.15). Its closing "Decided with the owner (2026-11-12)" section wins. Cards (§4.2 to §4.7, the payment window) are another lane's.

**Decisions this plan adds** (the spec is silent, or the brief overrides it):

1. **Answered means Telnyx's `call.answered` webhook**, not the media socket's `start`: Telnyx's docs do not say whether a stream asked for at dial starts at answer or while ringing, and the disclosure must be heard. So the listener also takes `POST /calls/events`, signed the same way (`timestamp|body`). `call.hangup` there, the media `stop` event and the socket closing all count as the other side's hang-up.
2. **The public address is a setting**, `calls.media_url` (`wss://host[:port]`), which the spec did not list: the daemon must tell Telnyx where to connect, and cannot learn the owner's funnel name itself. The signed string is `<timestamp>|<media_url>/calls/<token>`.
3. **Telnyx's public key and the API base are in the `[[service]]` entry** (`public_key`, and an optional `api` that defaults to `https://api.telnyx.com/v2`), so a test and the side container point the real client at the fake with no hidden switch.
4. **Replay:** a signature is refused when its timestamp is more than 300 s from now, when the same signature was seen before (kept for 600 s), and for media when the token was already used or its call is over.
5. **Utterances are cut by energy in the daemon** (20 ms frames; speech after 60 ms above the threshold, an utterance ends after 700 ms below it, is cut at 15 s, and under 300 ms is dropped); Silero still runs inside whisper-cli (`--vad`) on each utterance, so noise transcribes to nothing. The spec's "cut by Silero" needs a streaming VAD binary the image does not have.
6. **The call id is the proposal id** (`calls.id`), so the card, `/hangup 9`, the session `call-9` and the report `call-9` share one number.
7. **A call whose `business` or `purpose` names a healthcare or emergency service is refused** before the card (hospital, clinic, doctor, dentist, pharmacy, medical, ambulance, emergency, 911; 병원, 의원, 약국, 응급), beside the spec's card line and the child's prompt. zephyr still cannot tell a clinic's number from a shop's; this catches the calls that say so.
8. Hidden `Config` fields, `#[serde(skip)]`: `calls_off_floor` (tests run the listener outside a container), `calls_ring` (45 s: Telnyx's 30 s ring plus slack), `calls_silence` (20 s), `calls_now` (`None`; a fixed clock for the hours in tests).
9. **Not built** (YAGNI; the spec lists them, the owner's decisions do not need them): `calls.speech = "provider"`, `calls.countries`, `calls.prefixes` and `calls.languages` as settings (constants in `calls/mod.rs`), the cost line on the card (Telnyx publishes Canada's rate only in its portal), `approvals.strong_only = calls`, a separate `call` event on `zephyr.subscribe` (the transcript notices already reach the TUI and the web app as notices), `/activity`'s own calls list (the audit rows are there), `AnyTelephony` and a Rust `Fake` (the fake is an HTTP server the real client talks to), `doctor`'s authenticated read and funnel probe.

## Review Focus

1. **A call to an emergency, health or out-of-hours number is refused** before any card: `911`, `811`, `988`, a 900 number, a US and a Caribbean number, a clinic by name, a Toronto number at 21:45 on a Tuesday and 09:30 on a Saturday; and an `/ok` given out of hours leaves it pending. Tests in D2-1 (`refuses_*`) and D2-6 (`an_ok_out_of_hours_leaves_the_call_pending`).
2. **A private fact is never spoken:** a reply sentence holding a fact under `hold` never reaches Telnyx's socket, the fixed line is spoken in its place, a `held` line names the fact, and the owner is told. Test in D2-6 (`a_private_fact_is_never_spoken`).
3. **The other party's speech cannot approve or command anything, and it taints:** a heard `/ok 3` leaves proposal 3 pending; the report row has `derived = 'call'`; main's conversation is tainted after it; the call child is started with `--no-tools` and the plugin refuses any tool call from a `call-` session. Tests in D2-4 (`a_call_session_gets_no_tool`) and D2-6 (`what_they_say_is_never_a_command_and_taints`).
4. **The cap and `/hangup` end the call:** `/hangup N` makes the daemon call Telnyx's hangup at once; a call past its cap is ended by the daemon with the closing line; their hang-up makes the daemon hang up within 10 s. Tests in D2-6.
5. **The Telnyx media connection's signature is verified:** unsigned, signed with another key, signed over another URL, stale, replayed, a used token and an unknown path all get no socket. Tests in D2-3 (`verify_*`) and D2-6 (`the_listener_takes_only_telnyx`).
6. **The Telnyx API key is never in the agent's env or `mcp.json`:** a child's environment, `mcp.json`, the session files, state.db and the outbox hold no byte of it after a full call. Test in D2-6 (`the_api_key_stays_with_the_daemon`), again live in D2-8.
